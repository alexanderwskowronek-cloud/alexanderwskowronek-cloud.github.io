Design

Good is what remains once everything unnecessary is gone.

We don’t design things to look designed. Every decision has to answer these eight questions.

  1. 01

    Does it help?

    Every feature has to earn its place. If it doesn’t help, it never makes it into the app.

  2. 02

    Is it clear at once?

    If an app needs a manual, it isn’t finished. Using it should explain itself.

  3. 03

    Is it honest?

    No fake countdown, no small print. What an app does is clear before you download it.

  4. 04

    Does it hold back?

    The app speaks up when you need it, not when we need you. No notification whose only job is to pull you back.

  5. 05

    Will it still be good in five years?

    We don’t follow trends that look dated next year. Updates make an app better without reinventing it each time.

  6. 06

    Is every detail right?

    VoiceOver, large text, dark mode: none of this is optional. An app is finished only when all of it works.

  7. 07

    Could it use less?

    We keep the apps small and go easy on the battery. Every feature has to be worth the storage and computing time it costs.

  8. 08

    Can anything else go?

    In the end, only what can’t be left out remains. Then the app is finished.
